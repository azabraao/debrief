The 30-second read

Four questions, answered before your coffee is ready

01 · triage

What needs me right now?

Sessions that ended on a question, a denied permission, or an error rise to the top — with the exact question quoted, so you can answer and unblock the fleet.

02 · outcome

What did each session actually do?

Files edited, commands run, commits made, tests passed or failed — extracted from the transcript itself. Deterministic, not summarized by another model.

03 · spend

What did it cost?

Token-accurate, per-model API-equivalent value, cache reads and writes included. On a Max plan, that number is the value your subscription delivered.

04 · replay

What exactly happened at 3:12am?

A flight-recorder timeline of every prompt, thought, tool call, diff, and error — filterable, with jump-to-error and per-subagent replays.

How it works

Reads the transcripts Claude Code already writes

Every session lives in JSONL under ~/.claude/projects/. Debrief streams it — gigabytes in seconds — and derives the story deterministically.

◍ 100% local

Binds 127.0.0.1 only. Zero network requests, zero telemetry, zero accounts. Your code and your prompts stay on your machine — the demo flag exists so even screenshots don't need real data.

◍ Zero dependencies

One npm package, nothing else. No build step, no headless browser, no database. If you have Node, you have Debrief — installs in seconds, nothing to trust but the code you can read.

◍ Built for drift

The transcript format is undocumented and changes between versions. The parser treats every field as optional and every unknown line as skippable, so updates degrade gracefully — never a crash on day one of a new Claude Code release.

FAQ

Fair questions

Does any of my data leave my machine?
No. Debrief makes zero network requests — no telemetry, no update checks, no error reporting. The dashboard binds to 127.0.0.1 only. You can verify this in the source: there isn't an HTTP client in the codebase.
I'm on a Claude subscription — what does the dollar number mean?
It's API-equivalent value: what your usage would cost at Anthropic's published API list prices, computed per model with cache reads and writes priced correctly. For API users it's an estimate of spend; for Max subscribers it's the value your plan delivered — a number worth knowing either way.
Which agents does it work with?
Claude Code today — main sessions, subagents, and workflow fleets. Adapters for Codex CLI, Gemini CLI, and opencode are on the roadmap; the parser was built with multiple formats in mind.
Does it use an LLM to summarize my sessions?
No. Everything you see is derived deterministically from the transcript — file paths from tool calls, commits from git output, test results from runner output, costs from token counts. Same input, same debrief, every time. Nothing is sent to any model.
What does "free preview" actually mean?
Everything works, free, today — no trial timer, no locked features. The founding license is how professionals pay for tools they use daily, and it's an honor system while Debrief is new. Founding keys will carry into every future version.
Will this slow down my machine or interfere with Claude Code?
Debrief only reads the transcript files, never writes to them. Indexing 1.4GB of history takes about five seconds cold and 40 milliseconds warm; after that it re-reads only files that changed.
